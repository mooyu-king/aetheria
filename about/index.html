Keep Aetheria close.

Add the website to your home screen or desktop. The external game and videos still need an internet connection.

  • iPhone / iPad: open in Safari, tap Share, then Add to Home Screen.
  • Chrome / Edge: use the address-bar install icon or the browser menu’s install option, if offered.
  • Other browsers: bookmark this page using the browser menu.

About Aetheria Online

This independent website brings together browser access to Aetheria: Emberlight, practical controls, save help and selected video references. Our goal is to help you start a session and understand which edition you are playing.

Two different experiences

The embedded game is an independent single-player browser adventure. The original Aetheria Online is the multiplayer game published by AetheriaMMORPG. This guide does not operate the original servers, manage player accounts or transfer characters between editions.

Sources and images

Original-game information and reference images come from the creator’s itch.io listing. Captions identify these images as original-game references. Browser controls and save instructions follow the hosted Emberlight interface. The mountain crest is an original emblem for this independent guide, not the developer’s official logo.

Corrections and rights
